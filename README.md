# Projeto Prático — Caso Jurídico Fictício
 
## Finalidade
 
Este projeto demonstra um fluxo de análise de um caso jurídico
fictício utilizando organização de arquivos, sanitização de
dados, RAG manual, verificação, auditoria e revisão humana.
 
## Caso
 
O caso trata de uma compra fictícia realizada pela internet,
seguida de uma solicitação de cancelamento e de informações
sobre o tratamento dos dados pessoais da cliente.
 
## Estrutura
 
- entrada/: relato bruto;
- apoio/: caso sanitizado e fontes;
- docs/: especificação, limites e prompts;
- evidencias/: respostas, verificação, auditoria e revisão;
- entrega/: orientação final.
 
## Fontes
 
1. Lei nº 13.709/2018 — LGPD.
2. Lei nº 8.078/1990 — Código de Defesa do Consumidor.
 
## Limitações
 
Todos os dados e personagens são fictícios.
 
Nenhuma informação pessoal real, processo real ou documento
de cliente foi utilizado.
 
O projeto possui finalidade exclusivamente acadêmica.
